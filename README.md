## 史实基准

- 以 **《三国志·蜀书·先主传》（卷 32）** 为主；裴松之注单独标出。
- **"百折不挠"的史源**：陈寿评语「**然折而不挠，终不为下者**」——即"百折不挠"的原始表达。
- 数字：起兵 184 年（24 岁）→ 称帝 221 年（61 岁）= **37 年**，故副标题"三十七年不放弃"。
- ⚠️ **画面中的演义元素**（已在讲稿史实表中逐条标注）：桃园三结义、三件专属兵器（青龙偃月刀 / 丈八蛇矛）、旗面文字。**《三国志》对三人兵器零记载**，且《关羽传》用的是「策马**刺**良于万众之中」——"刺"与"大刀"其实对不上。
- 刻意**没有**讲的内容（对 6 岁不合适）：鞭督邮、两次妻儿被掳的细节、夷陵之败与病逝。

## 重建与发布

```bash
# 改了 pages/ 里的图或讲稿后，一条命令重建全部产物并发布
bash ../scripts/ship.sh            # 构建 + 提交 + 推送（推送后 Actions 自动部署，约 30 秒上线）
bash ../scripts/ship.sh --no-push  # 只构建不推送
```

`ship.sh` 会先**硬校验 `pages/` 顶层正好 10 张 PNG**（变体必须放进 `pages/_archive/`），再依次生成 PPTX / A4 图卡 / 大字拼音讲稿，把它们拷进 `downloads/`，最后重建网页并推送。

## 已知小瑕疵（不影响使用，如实记录）

- **P3**：刘备的耳朵只做到"圆形、大小正常"，不如其它页那样明显夸张（改为"斜扛长矛"的构图后，模型对大耳朵的响应变弱）。
- **P7**：院落已按需求升级为**围墙宅院**（夯土围墙 + 门屋敞开木门 + 堂屋 + 东西厢房 + 雪径，屋顶**一律茅草**以保住“茅庐”）；刘备耳朵为自然尺寸（**本页不再强调“大耳朵”识形键**，其余 9 页保持）；窗内剪影风格偏突兀；主屋屋顶与门框的前后遮挡略生硬。
- **P4**：城墙上有两只黄鸟（设计是一只）。
- **P8**：远处船上有个小人形似持械。
- **P9**：旗面上“汉”字四周的纸面是**平涂**（放大 3–4 倍能看出不同于原布纹的补面），观众尺度（投影/视网膜屏）下判定为完整自然；左右两侧群臣剪影的发髻形状不完全一致。
- **P2**：孩子抬起的手有 3–4 根手指（设计是"连指手套式、只露一根指头"）；两只耳朵左右大小略有不对称。母亲的脸已修正为完整五官（原版背对镜头、脸上没有五官）。

## 技术说明

- 出图：`image_generate`（provider `agnes-image`，模型 `agnes-image-2.5-flash`），2K / 16:9（2624×1472）。
- 风格：简化水墨 + 淡彩平涂 + 大量留白（`prompts/` 下每页一份完整 prompt）。
- **零文字原则**：AI 画面内不留任何文字，所有需要绝对正确的汉字（旗帜、标签）都由 **PIL 用毛笔字体合成**并单独送审。
- 质检：`scripts/vision_qc.py` 逐张判定（支持多 glob 批量、空 glob 会显式告警）。
