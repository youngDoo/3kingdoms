# 大耳朵刘玄德 · 三十七年不放弃

幼儿园大班「乐乐小主播」活动的三国故事演示 · 取材《三国志·蜀书·先主传》

## 这是什么

一个 10 页的静态幻灯网页，讲刘备的一生：从「和妈妈编草鞋的穷孩子」到「三十七年后当上皇帝」。
落点是**百折不挠**——用《三国志》里陈寿评刘备的原话「**折而不挠**」作底。

全片贯穿两个视觉母题：每页角落那盏**永不熄灭的小火苗**，和一路跟着他的**小黄雀豆豆**。

## 怎么用

- **← → / 空格** 翻页，**点右半屏**前进、**点左半屏**后退，手机上可左右滑动
- **N** 显示/隐藏讲稿与动作提示（给家长、老师看的提词层，观众看不到）
- **F** 全屏
- **Ctrl/Cmd + P** 直接打印成 PDF（每页一张）
- 网址带 `#3` 这样的锚点可以直接跳到第 3 页

## 史实说明（家长、老师可核对）

正文以《三国志·蜀书·先主传》为基准，**刻意不用《三国演义》情节**：

- 「桃园结义」《志》里没有 → 本片用《关羽传》原文「**寝则同床，恩若兄弟**」
- 「张飞鞭督邮」《志》里动手的是**刘备本人** → 本片因此整页不用
- 「草船借箭」「三英战吕布」「借东风」「五虎上将」均未采用

其中两处出自**裴松之注**而非陈寿正文，已在讲稿里标明：
「髀肉复生」（裴注引《九州春秋》）、临终遗诏（裴注引《诸葛亮集》）。

年龄换算均据《先主传》「时年六十三」逆推生年 161 年：黄巾起兵 24 岁、三顾茅庐 47 岁、
赤壁 48 岁、称帝 61 岁 —— 从起兵到称帝**整整 37 年**。
